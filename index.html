Overview

Baroque Technologies conducts applied systems research on the memory and compute bottlenecks of long-context Transformer inference. As autonomous coding and analytical workflows scale across long-horizon sessions, standard full-context attention becomes constrained by accelerator memory capacity (HBM/VRAM), host-to-device bandwidth, and attention dilution over large token histories.

We develop runtime memory-management layers and evaluation harnesses that enable frozen, instruction-tuned language models to operate over large historical states under strict accelerator memory budgets—preserving high-precision multi-hop recall without retraining base model weights.

Research & Engineering Areas

Bounded-Memory LLM Inference

Sub-linear KV-cache memory management and host-to-accelerator state tiering for open-weights Transformer architectures across consumer and data-center hardware.

Stateful Agent Infrastructure

Persistent session state and low-latency context retrieval middleware designed to prevent context-compaction loss in multi-turn engineering workflows.

Rigorous Long-Context Evaluation

Pre-registered, paired-bootstrap benchmarking of retrieval, variable tracking, and multi-hop reasoning across standardized 16K–128K+ evaluation suites.
